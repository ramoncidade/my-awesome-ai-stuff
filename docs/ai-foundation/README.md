# AI Engineering Foundation

This directory contains reusable reference knowledge for AI-assisted engineering. It complements, rather than duplicates, the executable workflows in `.agents/skills/` and the project-wide rules in `.cursor/rules/`.

## Contents

- [Stack reference](references/stack-reference.md): default Nuxt business application stack and selection guidance.
- [Project structure](references/project-structure.md): suggested responsibility boundaries for a Nuxt application.

## Design principles

- Keep permanent rules short and broadly applicable.
- Use skills for task-specific workflows with clear triggers and completion criteria.
- Keep detailed technical knowledge in references that can be consulted when needed.
- Prefer progressive disclosure over loading every document into every task.
- Treat defaults as starting points, not mandates. Existing repository conventions and explicit requirements take precedence.
